Linear → Settings → Security & access → Personal API keys. Se guarda solo en este Chrome. Solo se muestran las tareas asignadas a este correo en Linear. Vacío = el correo de tu perfil de Chrome; si ese no está en Linear, el dueño de la API key. "Mover a agente" le delega el issue. Para que lo programe Claude: en Linear, Settings → AI & agents → Cloud coding agent → modelo Claude.

Mandar a Claude (opcional)

Con tu propia tarea de Claude, el botón "Mandar a Claude" le pasa el issue y Claude te deja el PR a revisión. Sin token el botón no sale. Cómo crear la tarea: guía. Se genera en claude.ai/code/routines (tu tarea → disparo por API). Se guarda solo en este Chrome y no se vuelve a enseñar: vacío = se queda el que ya estaba. Para encontrar el repo de un issue cuando lo escribes como mi-empresa/repo en la descripción. Lo que ligas en Linear (PR, rama o link del proyecto) se detecta sin esto.

Preparar mi Linear

La extensión ordena tus issues con estas etiquetas: 🔍 necesita-triage, 👤 listo-para-humano, 🤖 listo-para-agente, ❓ necesita-info y el grupo riesgo (verde, amarillo, rojo). Este botón crea las que te falten; las que ya tienes no se tocan.
