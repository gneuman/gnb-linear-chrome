Política de privacidad de la extensión «¿Qué sigue?»

Última actualización: 5 de noviembre de 2026.

«¿Qué sigue?» es una extensión de Chrome que muestra tus issues de Linear y te recuerda tareas. Funciona entera en tu computadora: no tiene servidor propio.

Qué datos usa

  • Tu API key personal de Linear. La pegas tú en Ajustes. Sirve para leer tus issues y para cambiarlos cuando pulsas «Empezar» o «Mover a agente».
  • Tu correo. El que escribes en Ajustes o, si lo dejas vacío, el del perfil de Chrome. Sirve para encontrarte en Linear y mostrar solo los issues asignados a ti.
  • Tus issues de Linear y tus recordatorios. Se guarda una copia para abrir la ventana al instante y para avisarte de lo nuevo.

Dónde se guardan

Solo en el almacenamiento local de la extensión, en tu Chrome. No se sincronizan con otras computadoras.

Con quién se comparten

Con nadie más que Linear. La extensión solo habla con api.linear.app, con tu API key, para leer y cambiar tus issues. No se venden datos, no hay analítica ni publicidad, y no se mandan a ningún otro servidor, ni al del autor.

Cómo borrarlos

Al quitar la extensión de Chrome se borra todo lo que guardaba. Para cortar el acceso a Linear, revoca la llave en Linear → Settings → Security & access → Personal API keys.
